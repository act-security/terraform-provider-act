# act_current_identity (Data Source)

The tenant, region and service account the provider is authenticated as, from the public API `whoami` call the provider makes when it starts.

Use it to confirm which tenant and API key a configuration runs as.

## Example Usage

```terraform
data "act_current_identity" "this" {}

output "act_tenant" {
  value = data.act_current_identity.this.tenant_display_name
}
```
