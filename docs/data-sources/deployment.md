# act_deployment (Data Source)

One deployment, by ID or by what it covers. Use it to read a deployment another workspace or the Act console manages.

## Example Usage

```terraform
data "act_deployment" "production" {
  cloud  = "aws"
  target = "111111111111"
}

check "act_production_connected" {
  assert {
    condition     = data.act_deployment.production.status == "active"
    error_message = "Act cannot scan the production account."
  }
}
```

A lookup by `target` fails when no deployment or more than one deployment covers it. Look those up by `id`, or list them with `act_deployments`.

## Schema

### Optional

- `cloud` (String) `aws`, `azure` or `gcp`. Set it to narrow a `target` lookup.
- `id` (String) The deployment ID. Set this or `target`.
- `target` (String) Find the deployment that covers this target instead, such as a 12-digit AWS account ID or an organization ID. Set this or `id`. Exactly one deployment must match.

### Read-Only

- `created_at` (String) When it was created, in RFC 3339.
- `deletion_protection` (Boolean) Whether Act refuses to delete it.
- `name` (String) The name Act shows.
- `scope` (String) `account`, `organization`, `subscription`, `management_group` or `project`.
- `status` (String) `active`, `failed` or `pending_consent`.
- `tags` (Map of String) Act tags.
- `targets` (List of String) What the deployment covers: an account ID, or an organization ID with its root or organizational unit IDs.
- `update_available` (Boolean) True when the cloud side is older than the version Act recommends.
