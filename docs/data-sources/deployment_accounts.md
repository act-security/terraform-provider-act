# act_deployment_accounts (Data Source)

The member accounts a deployment resolves to, with each one's status. For an account deployment it is the account itself.

## Example Usage

```terraform
data "act_deployment_accounts" "failed" {
  deployment_id = act_aws_organization_deployment.this.id
  status        = "failed"
}

output "accounts_act_cannot_reach" {
  value = data.act_deployment_accounts.failed.account_ids
}
```
