# act_integration_types (Data Source)

The integration types this tenant can use, whether each is installed, and which of its fields are secret.

A type behind a feature that is not enabled for the tenant is left out.

## Example Usage

```terraform
data "act_integration_types" "all" {}

output "installable_types" {
  value = [for t in data.act_integration_types.all.types : t.type if t.installable]
}
```
