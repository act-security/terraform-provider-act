# act_notification_event_types (Data Source)

The event types a notification rule can use in this tenant, the conditions each takes, and the limits on rules and recipients.

## Example Usage

```terraform
data "act_notification_event_types" "all" {}

output "event_types" {
  value = data.act_notification_event_types.all.event_types[*].event_type
}
```
