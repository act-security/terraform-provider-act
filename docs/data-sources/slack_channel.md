# act_slack_channel (Data Source)

A Slack channel the tenant's Slack integration can post to, found by its exact name. Notification rules take channel IDs, not names.

The lookup fails when no channel matches and when more than one does. A private channel is visible only after the Act Slack app is invited to it.

## Example Usage

```terraform
data "act_slack_channel" "security" {
  name = "#security-alerts"
}

output "security_channel_id" {
  value = data.act_slack_channel.security.id
}
```

## Schema

### Required

- `name` (String) The channel name, with or without `#`, or a channel ID. Matched exactly, ignoring case.

### Optional

- `integration_id` (String) The Slack integration to search. Needed only when the tenant has more than one.

### Read-Only

- `channel_name` (String) The channel name as Slack spells it, without `#`.
- `id` (String) The channel ID, such as `C05PLATGRD2`.
