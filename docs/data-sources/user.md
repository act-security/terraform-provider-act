# act_user (Data Source)

An Act user of this tenant, found by their exact email address. Its `id` goes in the `user_ids` of a notification recipient.

## Example Usage

```terraform
data "act_user" "lee" {
  email = "lee@example.com"
}

output "lee_user_id" {
  value = data.act_user.lee.id
}
```

The lookup matches the whole address and never lists or searches, so it finds at most one user. A user who has left the tenant is not found.
