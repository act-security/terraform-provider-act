# act_notification_recipient (Resource)

A tenant-wide address-book entry for notification rules: a name and the email addresses and Slack channels it stands for. Rules reference it in `recipient_ids`. Notification rules are in preview; the tenant needs them enabled.

A recipient needs an `email` block, a `slack` block, or both.

## Example Usage

```terraform
data "act_email_integration" "this" {}

resource "act_notification_recipient" "platform" {
  name = "Platform team"

  email {
    integration_id = data.act_email_integration.this.id
    recipients     = ["platform@example.com"]
  }

  slack {
    integration_id = act_slack_integration.this.id
    channel_ids    = ["C05PLATGRD2"]
  }
}
```

Reference it from a rule's `recipient_ids` with its `id`, so Terraform deletes the rule's reference before the recipient. Act refuses to delete a recipient while any rule names it, and the error lists those rules.

## Schema

### Required

- `name` (String) The name Act shows, up to 100 characters. Unique in the tenant.

### Optional

- `email` (Block List) Send email. At most one block. Act stores addresses in lowercase; a plan never shows a change for a difference in case or order. (see [below for nested schema](#nestedblock--email))
- `slack` (Block List) Post to Slack. At most one block. (see [below for nested schema](#nestedblock--slack))

### Read-Only

- `id` (String) The recipient ID.
- `revision` (Number) The recipient's revision in Act. It goes up on every change.
- `rule_ids` (Set of String) The notification rules that reference this recipient. Act refuses to delete a recipient while any rule does.

<a id="nestedblock--email"></a>
### Nested Schema for `email`

Required:

- `integration_id` (String) The ID of the Act-managed email integration, from the `act_email_integration` data source.
- `recipients` (Set of String) The email addresses this recipient stands for, up to 100.


<a id="nestedblock--slack"></a>
### Nested Schema for `slack`

Required:

- `channel_ids` (Set of String) The Slack channel IDs this recipient stands for, up to 50, such as `C05PLATGRD2`. Act does not take channel names; look an ID up with the `act_slack_channel` data source.
- `integration_id` (String) The ID of the Slack integration, from `act_slack_integration` or the `act_integration` data source.
