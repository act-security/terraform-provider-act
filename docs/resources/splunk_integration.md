# act_splunk_integration (Resource)

A Splunk integration that sends Act events as OCSF through the HTTP Event Collector. One per tenant.

Create an index for Act events and an HTTP Event Collector token allowed to write to it. The HEC URL must be public https; Act does not send to private addresses. Act checks the connection before it saves anything, so an apply with credentials Splunk rejects fails and changes nothing.

## Example Usage

```terraform
variable "splunk_hec_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "act_splunk_integration" "this" {
  hec_url              = "https://http-inputs-acme.splunkcloud.com"
  hec_token_wo         = var.splunk_hec_token
  hec_token_wo_version = 1
}
```

Reference the integration from a notification rule with its `id`. The ID stays the same when you rotate the secret or change a setting.

## Secrets

Act never returns the HEC token. Set it one of two ways, never both:

| Argument | Terraform | Stored in the state |
|---|---|---|
| `hec_token_wo` with `hec_token_wo_version` | 1.11 and later | No. The value lives only in the configuration, so it can come from an ephemeral variable or an ephemeral resource. |
| `hec_token` | 1.5.7 and later | Yes, marked sensitive. Anyone who can read the state can read it. |

To rotate a write-only secret, change the value and increase `hec_token_wo_version`. The integration is updated in place. With `hec_token`, changing the value is enough.

On Terraform before 1.11, use `hec_token` with a sensitive variable:

```terraform
resource "act_splunk_integration" "this" {
  hec_url   = "https://http-inputs-acme.splunkcloud.com"
  hec_token = var.splunk_hec_token
}
```

Changing `hec_url` or `tls_verification` also sends the HEC token again: Act checks the new settings with the secret you configure and never reuses the stored one for them.

`hec_token_updated_at` records when Act last stored a new value. If it moves without Terraform, for example after someone rotates the secret in the Act console, the next plan updates the integration in place and sends the configured value again, with a warning.

## Schema

### Required

- `hec_url` (String) Your public HTTP Event Collector URL, such as `https://http-inputs-acme.splunkcloud.com`. Changing it sends the HEC token again.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `hec_token` (String, Sensitive) The HEC token, allowed to write to the index your notification rules name. Stored in the Terraform state. Set exactly one of `hec_token` and `hec_token_wo`; prefer `hec_token_wo` on Terraform 1.11 and later.
- `hec_token_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The HEC token, allowed to write to the index your notification rules name. Write-only: never stored in the plan or the state. Needs Terraform 1.11 or later. Change `hec_token_wo_version` to send a new value.
- `hec_token_wo_version` (Number) Any number you choose. Changing it sends `hec_token_wo` to Act again, in place.
- `tls_verification` (String) How Act checks the HEC certificate: `verify` (default), `splunk_default_ca` for Splunk's default certificate, or `none`, which lets anyone between Act and Splunk read the token. Changing it sends the HEC token again.

### Read-Only

- `display_name` (String) The name Act shows for the integration.
- `health_note` (String) What to do about an unhealthy connection. Null while connected.
- `health_reason` (String) Why the connection is unhealthy, when Act reports a reason. Null while connected.
- `hec_token_updated_at` (String) When Act last stored a new `hec_token`, in RFC 3339. When it moves without Terraform, for example after a rotation in the Act console, the next plan sends the configured value again.
- `id` (String) The installation ID. It stays the same when you rotate `hec_token` or change a setting, so notification rules can reference it.
- `status` (String) The connection status: `connected`, `pending`, `error` or `disconnected`.

## Import

Import by integration ID, or by `splunk`, since a tenant has at most one Splunk integration:

```shell
terraform import act_splunk_integration.this splunk
```

Import cannot read the secret. Set `hec_token` or `hec_token_wo` in the configuration; the first apply sends it once.
