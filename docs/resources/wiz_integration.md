# act_wiz_integration (Resource)

A Wiz integration, connected with a Wiz service account so Act can read its issues. One per tenant.

Create a Wiz service account of type **Custom Integration (GraphQL API)** with `read:issues`, `read:security_frameworks`, `read:projects` and `read:resources`. Act checks the connection before it saves anything, so an apply with credentials Wiz rejects fails and changes nothing.

## Example Usage

```terraform
variable "wiz_client_secret" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "act_wiz_integration" "this" {
  client_id                = "act-reader"
  api_endpoint_url         = "https://api.us17.app.wiz.io/graphql"
  client_secret_wo         = var.wiz_client_secret
  client_secret_wo_version = 1
}
```

Reference the integration from a notification rule with its `id`. The ID stays the same when you rotate the secret or change a setting.

## Secrets

Act never returns the client secret. Set it one of two ways, never both:

| Argument | Terraform | Stored in the state |
|---|---|---|
| `client_secret_wo` with `client_secret_wo_version` | 1.11 and later | No. The value lives only in the configuration, so it can come from an ephemeral variable or an ephemeral resource. |
| `client_secret` | 1.5.7 and later | Yes, marked sensitive. Anyone who can read the state can read it. |

To rotate a write-only secret, change the value and increase `client_secret_wo_version`. The integration is updated in place. With `client_secret`, changing the value is enough.

On Terraform before 1.11, use `client_secret` with a sensitive variable:

```terraform
resource "act_wiz_integration" "this" {
  client_id        = "act-reader"
  api_endpoint_url = "https://api.us17.app.wiz.io/graphql"
  client_secret    = var.wiz_client_secret
}
```

Changing `client_id` or `api_endpoint_url` also sends the client secret again: Act checks the new settings with the secret you configure and never reuses the stored one for them.

`client_secret_updated_at` records when Act last stored a new value. If it moves without Terraform, for example after someone rotates the secret in the Act console, the next plan updates the integration in place and sends the configured value again, with a warning.

## Schema

### Required

- `api_endpoint_url` (String) Your Wiz API endpoint, such as `https://api.us17.app.wiz.io/graphql`. Changing it sends the client secret again.
- `client_id` (String) The client ID of the Wiz service account. Changing it sends the client secret again.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `client_secret` (String, Sensitive) The client secret of the Wiz service account. Stored in the Terraform state. Set exactly one of `client_secret` and `client_secret_wo`; prefer `client_secret_wo` on Terraform 1.11 and later.
- `client_secret_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The client secret of the Wiz service account. Write-only: never stored in the plan or the state. Needs Terraform 1.11 or later. Change `client_secret_wo_version` to send a new value.
- `client_secret_wo_version` (Number) Any number you choose. Changing it sends `client_secret_wo` to Act again, in place.

### Read-Only

- `client_secret_updated_at` (String) When Act last stored a new `client_secret`, in RFC 3339. When it moves without Terraform, for example after a rotation in the Act console, the next plan sends the configured value again.
- `display_name` (String) The name Act shows for the integration.
- `health_note` (String) What to do about an unhealthy connection. Null while connected.
- `health_reason` (String) Why the connection is unhealthy, when Act reports a reason. Null while connected.
- `id` (String) The installation ID. It stays the same when you rotate `client_secret` or change a setting, so notification rules can reference it.
- `status` (String) The connection status: `connected`, `pending`, `error` or `disconnected`.

## Import

Import by integration ID, or by `wiz`, since a tenant has at most one Wiz integration:

```shell
terraform import act_wiz_integration.this wiz
```

Import cannot read the secret. Set `client_secret` or `client_secret_wo` in the configuration; the first apply sends it once.
